# 10. Từ điển thuật ngữ

| Thuật ngữ | Ý nghĩa trong tài liệu |
|---|---|
| Server / Guild | Cộng đồng Discord mà bot được mời vào. |
| Admin | Chủ server hoặc người được cấp quyền quản trị tối cao theo cấu hình. |
| Quản trị viên / Moderator | Người xem xét vụ việc và quản lý thành viên theo quyền server cấp. |
| Log / Nhật ký | Bản ghi sự kiện bot nhận được và được phép lưu. |
| Vụ việc | Hồ sơ kiểm duyệt do bot hoặc thành viên tạo để người có quyền xem xét. |
| Đề xuất | Nhận định/hành động được bot gợi ý; không tự động thi hành hình phạt. |
| Để treo | Tạm hoãn quyết định để chờ thêm thông tin hoặc người duyệt. |
| CAPTCHA | Bước kiểm tra thành viên mới trước khi cấp quyền truy cập server. |
| Chưa xác minh | Role trạng thái dành cho thành viên chưa hoàn tất xác minh. |
| Đã xác minh | Role trạng thái đối ứng sau khi xác minh thành công hoặc được cấp thủ công. |
| Lobby voice | Kênh voice mà thành viên vào để yêu cầu bot tạo phòng voice tạm thời. |
| Phòng tạm | Kênh voice được tạo động và tự xóa khi không còn thành viên người dùng. |
| ID phòng | Mã duy nhất giúp tìm/nhập phòng theo quy tắc quyền đã cấu hình. |
| Slash Command | Lệnh ứng dụng Discord hiển thị trong giao diện lệnh. |
| Múi giờ | Quy tắc chuyển thời gian UTC sang giờ địa phương để hiển thị lịch/nhắc. |
| Dashboard | Trang web quản trị bot dự kiến ở giai đoạn sau. |
